# Лабораторные работы по Python

Репозиторий содержит выполненные лабораторные задания по Python.

В рамках работы были изучены базовые конструкции языка, а также основные структуры данных и способы их применения на практике.

---

## Структура репозитория

```
python_lab/
├── README.md — Описание проекта
├── task_01_passport.py — Задача 1 (паспорт объекта)
├── task_02_room_calc.py — Задача 2 (параметры помещения)
├── task_03_temperature.py — Задача 3 (конвертер температур)
├── task_04_day_of_week.py — Задача 4 (рабочий график)
├── task_05_discount_calc.py — Задача 5 (калькулятор скидки)
├── task_06_materials.py — Задача 6 (каталог материалов)
├── task_07_price_dict.py — Задача 7 (прайс-лист)
├── task_08_sets.py — Задача 8 (анализ заказов)
├── task_09_addresses.py — Задача 9 (очистка адресов)
└── task_10_warehouse.py — Задача 10 (система склада)
```

## Используемые темы

* Переменные и типы данных
* Условные операторы (`if / elif / else`)
* Списки (`list`)
* Словари (`dict`)
* Множества (`set`)
* Строки и их обработка
* Циклы (`for`)
